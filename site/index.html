Security first

A wall panel sits on your home network and often shows the controls to your front door. Open Kiosk treats it that way.

  • Origin lock. Only your dashboard's address can load. Links elsewhere are ignored.
  • No file access from web pages, no mixed content, no intent: or javascript: URLs.
  • No open bridge. Native capabilities are opt-in, typed and origin-checked. No shell, no filesystem.
  • Remote APIs off by default, token-authenticated with scopes, loopback-only unless you choose otherwise.
  • Nothing phones home. No analytics, no vendor cloud, no account.

Fast by design

On a 2 GB panel every megabyte matters, so nearly all of it should go to your dashboard.

  • Plain Kotlin on the Android framework. No AndroidX, no Compose, no heavy libraries.
  • One WebView, created once and rebuilt only when its renderer dies.
  • Shrunk with R8, measured against published targets: cold start under 5 seconds, 72-hour soak tests.

Get started

  1. Install

    Download the APK from Releases, or build it yourself.

    adb install open-kiosk.apk

  2. Point it at your dashboard

    Open the app and enter your URL, for example http://homeassistant.local:8123/.

  3. Make it the Home app

    When Android asks, choose Open Kiosk. The panel now boots straight into your dashboard.

Questions

Is Open Kiosk really free?

Yes. It is open source under the Apache License 2.0, free for personal and commercial use, with no paid tier.

Does it work with Home Assistant?

Yes. Any web dashboard works, including Home Assistant's own UI and custom dashboards. MQTT discovery for Home Assistant is planned for v0.2.

Which devices are supported?

Android 8.1 (API 27) or newer with Android System WebView: wall panels, tablets and TV boxes. Vendor-specific hardware such as knobs and secondary screens gets experimental adapters.

Do I need root?

No. A fully locked-down kiosk uses Android's own device-owner Lock Task mode, which is optional and documented separately.

Is it an alternative to Fully Kiosk Browser?

It covers the same core use case, a locked-down dashboard browser, as a free, open-source project. It is independent and not affiliated with Fully Kiosk Browser.
